# Contributing to Statigo

Thanks for your interest in contributing! Here are some simple guidelines to help your contribution get accepted quickly.

1. Fork the repository and create a feature branch from `main`:

```bash
git checkout -b feat/your-feature
```

2. Make changes with clear, focused commits. Follow conventional commit style where possible.

3. Keep code style consistent. Run linters or formatters if present. If not, follow the existing project style.

4. Open a pull request describing the change, why it's needed, and any migration or testing steps.

5. Add tests for bug fixes or features when feasible.

6. Be responsive to review comments; maintainers may request updates.

If you're unsure where to start, check the issue list or open one describing your idea.
